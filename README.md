# 防火・防災 Study

防火・防災管理者講習の学習補助サイトです。

## 主な機能
- 第1章〜第8章を講習カリキュラムに合わせて表示
- 1-1、4-2、7-3など項目単位の小テスト
- 各章まとめテスト
- 全8章総合テスト
- ランダム10問
- 間違い問題だけの再テスト
- 復習ノート
- 学習進捗・ベストスコア・苦手問題を端末内に自動保存
- iPhone / Android / PC対応
